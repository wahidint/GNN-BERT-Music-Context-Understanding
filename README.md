# Understanding Musical Context Using a Hybrid BERT and Graph Neural Network Framework

## Overview
A multimodal music understanding project combining:

- BERT for semantic music description understanding
- Graph Neural Networks for structural representation learning
- Fusion approaches for combining modalities

## Tasks

1. BERT-based MusicCaps multi-label classification
2. GNN-based music structural learning
3. BERT-GNN multimodal fusion

## Run

Install dependencies:

pip install -r requirements.txt

Open:

notebook/Final_Model.ipynb

and run the notebook.
